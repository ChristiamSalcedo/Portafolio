# ⚡ Christiam Salcedo — Personal Portfolio

Portafolio web personal de alto impacto visual y rendimiento, construido con foco en estética **Cyberpunk / Dark Mode** y micro-interacciones.

👉 **Demo en vivo:** [christiamsalcedo.github.io/Portafolio](https://christiamsalcedo.github.io/Portafolio/)

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Variables, Flexbox, CSS Grid), JavaScript (ES6+).
- **Typography:** Clash Display, Satoshi, Geist.
- **Form Handling:** Web3Forms API.
- **Hosting:** GitHub Pages.

## 🕹️ Features
- Responsive Design (Mobile First & Desktop).
- Animaciones SVG interactivas en tiempo real.
- Formulario de contacto funcional sin backend dedicado.
- Easter Egg estilo *Cyberpunk 2077* con enlace histórico (Data Shard).
